# Contributor agent instructions

1. Read `README.md` and `PROVENANCE.json`, then run `npm install --ignore-scripts`, `npm run dev`, and `npm run validate`.
2. Work only in this repository. Do not request private code, production credentials, customer data, provider accounts, databases, or deployment access.
3. Use obvious synthetic data and localhost resources. Never add `.env` files, credentials, real contact identities, external runtime URLs, proxy fallbacks, provider clients, or deployment workflows.
4. Preserve the permanent sandbox label, fail-closed routes, simulated co-author label, inert preview forms, and disabled release actions.
5. Test desktop and mobile, push only a feature branch, and open a pull request. Never merge or deploy directly.

## Maintaining this file

Keep this file short and project-wide. Add only durable guidance that most future contributors need, and point to authoritative project files instead of duplicating details.
